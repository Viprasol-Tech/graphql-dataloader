# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Please **do not** open public issues for security problems.

Email [support@viprasol.com](mailto:support@viprasol.com) with details and steps
to reproduce. We aim to acknowledge reports within 72 hours and to ship a fix or
mitigation as quickly as possible. We will credit reporters who wish to be named.
